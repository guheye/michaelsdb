# Security

## Reporting a vulnerability

Please report security vulnerabilities **privately** so they can be addressed before public disclosure.

**Preferred:** Use [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) for this repository if private reporting is enabled on the project.

If that is not available, open a generic issue asking for a secure contact channel, or email the repository maintainer if a contact address is listed in the README or GitHub profile.

Please include:

- A description of the issue and its impact
- Steps to reproduce (if safe to share)
- Affected versions or commits, if known

Do not report security issues in public issues or pull requests.

## Supported versions

Security fixes are applied to the default branch (`main`) unless otherwise noted. Use the latest commit when deploying.
